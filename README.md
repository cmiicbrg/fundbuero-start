Fundbüro App für die Schule.

## Features
- Fundstücke eintragen mit Foto (Upload nach Dropbox)
- Suche
- E-Mail an die Klasse, wenn etwas gefunden wurde
- Login für Lehrer

## Start
npm install
npm start

läuft auf http://localhost:3000
